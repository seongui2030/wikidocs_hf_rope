# 11. 종목별 자세 자동 진단 알고리즘

## 1. 학습 목표
* 영상 전체에서 측정된 관절 각도의 평균값을 계산합니다.
* 파이썬 조건문(`if-else`) 구조를 사용하여 체육 동작의 양호/주의/경고 등 피드백을 산출하는 알고리즘을 작성합니다.

## 2. 자동 진단 조건문 로직 원리
* **평균 관절 각도 산출**: 프레임별 수집된 각도 데이터의 평균값을 기준으로 동작 수행 품질을 판정합니다.
* **임계값(Threshold) 비교**: 각 운동 종목 특성에 맞추어 최적 각도 범주 내 포함 여부를 확인합니다.

## 3. 소스코드 예시

```python
def diagnose_posture(avg_elbow, avg_trunk):
    feedback_msgs = []
    
    # 1. 팔꿈치 각도 진단
    if 80 <= avg_elbow <= 120:
        feedback_msgs.append("✅ 1. 팔꿈치 각도: 양호합니다.")
    else:
        feedback_msgs.append("⚠️ 1. 팔꿈치 각도: 주의가 필요합니다. 팔을 과도하게 펴거나 굽히지 마세요.")
        
    # 2. 상체 기울임 진단
    if avg_trunk < 15:
        feedback_msgs.append("✅ 2. 상체 기울임: 양호합니다.")
    else:
        feedback_msgs.append("🚨 2. 상체 기울임: 경고! 상체가 앞쪽으로 많이 기울어졌습니다.")
        
    return "\n".join(feedback_msgs)
```
